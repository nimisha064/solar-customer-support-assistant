# ☀️ Solar Customer Support Assistant

A Python and Streamlit-based customer support chatbot designed to provide information about a solar company's products, services, installation process, support, and contact details.

## 🚀 Features

- Customer identification using WhatsApp number
- Collects basic customer information:
  - Name
  - Location
  - Requirement type
- Interactive chat interface using Streamlit
- Provides information from a structured company knowledge file
- Handles common customer queries about:
  - Solar products
  - Services
  - Benefits of solar energy
  - Installation process
  - Customer support
  - Contact details
  - Company information
- Identifies basic sales-related queries such as price, quotation, purchase, and orders
- Maintains chat history during the session

## 🛠️ Technologies Used

- Python
- Streamlit
